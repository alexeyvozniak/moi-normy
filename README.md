# Правило

Личный PWA-трекер молитвы, чтения, созерцательной практики и других регулярных норм.

## Изображения

- `images/hero.webp` — горы, бамбук и красное солнце.
- `images/prayer_person_beads.webp` — человек с молитвенными чётками.
- `images/reading_person_book.webp` — человек читает книгу.
- `images/contemplation_looking_up.webp` — человек в задумчивости смотрит вверх.
- `images/samurai_training.webp` — самурай тренируется с мечом.
- `images/selfcare_onsen.webp` — человек отдыхает в горячей ванне среди гор.
- `images/calligraphy_ink.webp` — кисть, тушь и тушечница.
- `images/walking_path.webp` — одинокий путник на горной дороге.
- `images/books_notes.webp` — закрытые книги/тетрадь и карандаш.
- `images/open_book.webp` — открытая книга на фоне гор.
- `images/enso.webp` — тушевый круг энсо с красным солнцем.
- `images/stat_active.webp` — круглый зелёный значок с горами.
- `images/stat_debt.webp` — круглый терракотовый значок с солнцем и волнами.
- `images/stat_done.webp` — круглый зелёный значок с чек-листом.

Обои лежат отдельно в корне репозитория и не участвуют в работе приложения.
